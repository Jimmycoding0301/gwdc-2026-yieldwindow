# Public Nile evidence

- [`registry-deployment.json`](registry-deployment.json) records the independently verified ReceiptRegistry deployment.
- [`yieldwindow-receipt.json`](yieldwindow-receipt.json) records the canonical demo plan, digest, public transaction and independent verification result.

These files contain public testnet data only. They contain no private key, API key, raw signed transaction or seed phrase.

The receipt proves that the test wallet committed the displayed plan digest on Nile. It does not prove a JustLend deposit, redemption, rebalance, position or realized yield.
